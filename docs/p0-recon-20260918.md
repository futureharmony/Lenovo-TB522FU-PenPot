# P0 侦察结果（2026-09-18，TB522FU 实机）

## 结论：TB710FU 的笔硬件接口在 TB522FU 上几乎全有等价物，移植难度下调

| TB710FU 节点 | TB522FU 等价物 | 状态 |
|---|---|---|
| /sys/devices/virtual/factory/interface/hw_info/pen1_hall / pen2_hall | /sys/devices/virtual/hall/och1909/hall1_1, hall1_2, hall2, hall3（四路 Hall，驱动 och1909，I2C 11-000c） | ✅ 存在可读，**语义待标定** |
| /sys/devices/virtual/lenovo_penraw/lenovo_penraw/uevent | **同名节点存在**（MAJOR=492），内核 PEN_FRAMEWORK uevent 通道大概率直接可用 | ✅ 存在 |
| /proc/pen_wakeup_mode, pen_wakeup_switch | **同名**（当前 0/0，system:proc_tp） | ✅ 存在 |
| CPS 充电芯片 I2C 2-0041 | **11-0041 wls-charger-cps8601**（CPS8601 无线充，同地址 0x41） | ✅ 存在，路径改 i2c-11 |
| CPS GPIO 上电 gpiochip0 线号 10/108 | TB522FU 未知，须从 dts/kernel 重新确认 | ⚠️ 待查 |
| 笔 PID | Pen Pro 2 = 17EF:0x622E = **25134，恰在原方案 LENOVO_PRODUCTS 列表内** | ✅ 官方兼容 |
| hwinfo | /sys/devices/virtual/hwinfo/interface/hardware_info/（结构对应 factory/interface/hw_info，hall 条目读 "Not support!"） | 可作旁路 |
