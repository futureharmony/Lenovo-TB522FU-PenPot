## 充满断电控制——已实测打通（2026-09-18 11:3x）
- **控制节点**：`/sys/bus/i2c/devices/11-0041/tx_status`（root 可写，driver=cps-wls-charger，DT 节点 cps-wls-charger-l@41）
- **写入格式**：只认裸数字！`echo 1` → `cps_boost_mode:1, cps_wls_en:1`；`echo 0` → 全 0。
  ⚠️ 任何带字样的字符串（如 `cps_wls_en:1`）都被解析为 0——踩过一次坑，已实测确认。
- **动画**：`echo 0` 即停无线发射（充笔断电），`echo 1` 恢复。实测往返成功。
- **充满判据**：`settings get global ipe_pencil_battery_level`（=100）与 `lenovo_pen_bridge_cap_pen_info` 第二字段（6;100;...）；`cps_wls_tx/online` 与 `wls_tx` 侧读数在笔满后归零，可作旁证。
- **旧方案对照**：TB710FU 用 gpiochip0 gpio10/108 keeper；TB522FU 用本节点，更干净。
- **待补**：ipe_pencil_charging_state 恒 0（内核在充、IPeManager 状态不跟）→ 移植版需把 cps 状态喂回去。
